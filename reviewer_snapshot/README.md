# Reviewer snapshot

This directory contains a pre-generated SOPRAS dashboard for the rich synthetic reviewer profile. It is served automatically when the configured database name contains `_review`, so reviewers do not need to wait for the full analysis pipeline on first page load.

- Source: deterministic synthetic records generated by `scripts/build_rich_review_demo.py`
- Scale: 2,430 articles and 140 comments in the basin tables
- Yellow River: 1,097 articles and 59 comments
- Banner: the dashboard explicitly identifies the snapshot as a synthetic reviewer demo
- No real platform records or private identifiers are included
