# SoftwareX Release Checklist

## Repository

- [ ] Repository is public and hosted on GitHub.
- [ ] The manuscript version uses an annotated tag such as `v0.1.2`.
- [ ] `README.md`, `LICENCE.txt`, and `CITATION.cff` exist at that tag.
- [ ] Python code, templates, requirements, and setup documentation are included.
- [ ] Raw platform records, database dumps, model weights, logs, credentials, and generated artifacts are absent.

## SoftwareX metadata

- [ ] C1 current code version matches the tag.
- [ ] C2 points to the tagged GitHub tree.
- [ ] C3 lists MIT License.
- [ ] C4 lists git.
- [ ] C5 lists languages, tools, and services.
- [ ] C6 lists compilation and runtime requirements.
- [ ] C7 points to README documentation.
- [ ] C8 contains a working support email.

## Manuscript support

- [ ] Architecture documentation is available.
- [ ] Data setup and data governance are documented.
- [ ] Methods and model limitations are documented.
- [ ] Reproduction steps and expected health endpoint are documented.
- [ ] Screenshots and manuscript figures correspond to the tagged release.
